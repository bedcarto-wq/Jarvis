# Шаблоны

Шаблон — именованный сценарий из блоков. Его запускают голосом («Джарвис, запусти шаблон
рабочий режим» или просто по фразе запуска шаблона), кнопкой в «Библиотеке» или из другого шаблона.
Шаблоны хранятся в `%LOCALAPPDATA%\JARVIS\templates\` как JSON и могут импортироваться/экспортироваться.

## Редактор

Раздел «Редактор шаблонов»: слева — дерево блоков, в центре — палитра, справа — свойства блока.
Блоки можно добавлять, перетаскивать (в том числе внутрь «Если»/«Повтор»), дублировать,
отключать, удалять. Кнопки: «Проверить», «Сохранить», «Тестовый запуск», «Новый», «Копия»,
«Импорт», «Экспорт». Валидатор показывает ошибки (пустые параметры, неизвестный шаблон,
циклический вызов, превышение лимитов) до запуска.

## Блоки (24 вида)

| Группа | Блоки |
|---|---|
| Окна и программы | Запуск приложения, Переключение на окно, Закрытие окна, Свернуть окно, Развернуть окно |
| Ожидание | Ожидание программы, Ожидание элемента, Ожидание времени |
| Зрение | Поиск текста на экране, Нажатие элемента |
| Мышь и клавиатура | Действие мышью (перемещение, клик, двойной, правый, перетаскивание), Ввод текста, Нажатие клавиш (сочетание записывается с клавиатуры) |
| Интернет | Открытие сайта |
| Файлы | Создание файла, Перемещение/переименование (отменяемо), Удаление (в корзину) |
| Система | Изменение громкости, Системная операция (скриншот, рабочий стол, блокировка, выключение…), Сказать фразу |
| Логика | Условие (если/иначе), Повтор, Запуск другого шаблона, Завершение шаблона |

**Условия:** окно существует, окно активно, текст на экране, элемент существует, файл существует,
предыдущий шаг успешен, истёк тайм-аут; любое условие можно инвертировать («НЕ»).

**Параметры любого блока:** число попыток (по умолчанию 3, максимум 10), «продолжать при ошибке»,
пометка «опасный» с категорией (тогда перед шагом спрашивается подтверждение), комментарий.

## Лимиты

Повторов — до 100 (настраивается до 1000), вложенность шаблонов — до 8 (до 16), попыток — до 10.
Циклические вызовы шаблонов блокируются. Любой шаблон прерывается стоп-словом, кнопкой «Стоп»
или пунктом трея; все зажатые клавиши и кнопки мыши при этом отпускаются.

## Создание голосом

```
Джарвис, создай шаблон
Добавь запуск хром
Добавь ожидание 3 секунды
Добавь открытие сайта ютуб
Добавь громкость 30
Назови его вечерний стрим
Сохрани
```

Поддерживаемые фразы «добавь …»: запуск/открытие <программа>, переключение на <программа>,
закрытие/сворачивание/разворачивание, сайт <название или адрес>, ожидание N секунд/минут,
скриншот, рабочий стол, громкость N, шаблон <имя>, завершение. «Отмени шаблон» — отмена.
Сложные шаги (клики, условия) удобнее добавить потом в редакторе.

## Пример JSON

```json
{
  "Name": "Рабочий режим",
  "VoicePhrases": ["рабочий режим"],
  "Steps": [
    { "Kind": "LaunchApp", "Parameters": { "app": "chrome" } },
    { "Kind": "WaitForApp", "Parameters": { "app": "chrome", "timeoutMs": "10000" } },
    { "Kind": "OpenUrl", "Parameters": { "url": "https://github.com" } },
    { "Kind": "SetVolume", "Parameters": { "mode": "set", "value": "30" } }
  ]
}
```
(Точные имена полей — см. экспортированный из редактора файл.)
