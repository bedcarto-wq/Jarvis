# Совместимость

| Система | Статус |
|---|---|
| Windows 11 x64 (23H2, 24H2) | Целевая платформа. .NET 10 официально поддерживается. |
| Windows 10 x64 22H2 (Home/Pro) | Должна работать (минимальная версия приложения — 10.0.17763 / 1809). Поддержка этой редакции Windows 10 Microsoft завершена в октябре 2025 г., поэтому .NET 10 официально её не поддерживает — проблемы возможны, но не ожидаются. |
| Windows 10 Enterprise LTSC / IoT | Официально поддерживается .NET 10. |
| Windows Server 2022/2025 | Сборка и самопроверка выполняются на раннере GitHub `windows-latest`. |
| Windows ARM64, x86 (32 бит) | Не поддерживается (сборка только win-x64; нативная DLL x64). |
| Linux / macOS | Только сборка и тесты платформенно-независимой части. |

## Слабые компьютеры и HDD

JARVIS не требует видеокарты и работает на 2 ядрах / 4 ГБ ОЗУ / HDD с профилем «Слабый ПК»
(см. [PERFORMANCE.md](PERFORMANCE.md)). Тайм-ауты на таком профиле длиннее, фоновые задачи выполняются по одной,
операции с диском не блокируют интерфейс. Подобрать профиль поможет бенчмарк ([BENCHMARK.md](BENCHMARK.md)),
который запускается только вручную. Реальная работа на слабом ПК пока не проверялась — нужна ручная проверка.

## Зависимости ОС

* Микрофон и разрешение доступа к нему для классических приложений.
* `tar.exe` (есть в Windows 10 1803+) — для скрипта загрузки моделей.
* Visual C++ Redistributable 2015–2022 x64 — для Tesseract и PocketSphinx (обычно уже установлен).
* Русский голос SAPI — для голосовых ответов (необязательно).
* Масштабирование экрана: приложение Per-Monitor DPI Aware v2; координаты UIA/OCR учитывают DPI,
  но на конфигурациях с разным масштабом мониторов стоит проверить работу якорей вручную.
