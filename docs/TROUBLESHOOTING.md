# Решение проблем

| Симптом | Причина и решение |
|---|---|
| «Модель не найдена» на главной | Запустите `scripts\install-models.cmd` или укажите путь к папке `vosk-model-small-ru-0.22` в разделе «Голос». Если браузер скачивает не тот файл, скачайте вручную https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip и распакуйте в `%LOCALAPPDATA%\JARVIS\models`. |
| «Не удалось загрузить pocketsphinx.dll» | Файл должен лежать рядом с `JARVIS.exe`. Используйте сборку из GitHub Actions или соберите `scripts/build-pocketsphinx.ps1`. Может понадобиться [Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe). |
| JARVIS не реагирует на голос | Проверьте микрофон в разделе «Голос» (индикатор уровня), разрешение Windows: Параметры → Конфиденциальность → Микрофон → «Разрешить классическим приложениям». Понизьте порог VAD. |
| Срабатывает на посторонние звуки | Повысьте порог VAD и строгость, используйте гарнитуру. |
| Путает команды | Добавьте программе русские синонимы, говорите фразу целиком, увеличьте тайм-аут конца речи. Помните: распознаются только фразы из грамматики. |
| Нет голосовых ответов / английский голос | Установите русский голос: Параметры → Время и язык → Речь → Добавить голоса. Выберите его в разделе «Голос». |
| SAPI-распознаватель «недоступен» | Русский распознаватель SAPI есть не во всех Windows. Используйте PocketSphinx (по умолчанию). |
| OCR не работает | Нужны `rus.traineddata`/`eng.traineddata` из репозитория `tesseract-ocr/tessdata` (не `tessdata_fast`/`tessdata_best` — они только для нейросетевого LSTM-движка, который не используется). Нужен VC++ Redistributable x64. |
| Не нажимается кнопка в программе | Программа может не поддерживать UI Automation — сделайте якорь: наведите курсор и скажите «Джарвис, запомни как <имя>». Окна администратора недоступны из обычного процесса. |
| Не управляет окном игры | Полноэкранные игры часто игнорируют SendInput/активацию окна — ограничение Windows/игры. |
| Зажалась клавиша | Скажите стоп-слово или нажмите «Стоп» — JARVIS отпустит все клавиши. |
| Повреждён файл настроек | JARVIS переносит его в `%LOCALAPPDATA%\JARVIS\corrupt\` и запускается с настройками по умолчанию. |
| Не запускается вторая копия | Так и задумано: повторный запуск показывает окно уже работающего JARVIS. |

Режим отладки (раздел «Производительность») пишет подробный журнал в `%LOCALAPPDATA%\JARVIS\logs`.
Самопроверка: `JARVIS.exe --selftest --report отчет.txt` (см. BUILD.md).
