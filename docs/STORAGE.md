# Хранение данных

Все данные лежат локально в `%LOCALAPPDATA%\JARVIS` и никуда не отправляются.

| Папка/файл | Содержимое |
|---|---|
| `settings.json` | настройки, включая активный профиль и значения параметров производительности |
| `profiles\` | пользовательские профили (JSON, схема 1) |
| `reports\` | отчёты бенчмарков |
| `exports\` | экспорт профилей и отчётов по умолчанию |
| `benchmark-audio\` | (необязательно) ваши записи для оценки точности распознавания |
| `templates\`, `apps.json`, `anchors.json` | шаблоны, каталог программ, привязки элементов |
| `models\`, `tessdata\` | модели распознавания речи и OCR |
| `logs\` | журнал (в режиме отладки) |
| `corrupt\` | повреждённые файлы, перемещённые при загрузке |

## Дополнительное место (например, HDD)

На странице «Производительность» → «Хранение данных» можно указать папку на втором диске для экспорта отчётов и
профилей. Перед записью JARVIS проверяет, что папка доступна для записи (`StorageLocations.Probe`). Если диск
отключён или папка недоступна, файл сохраняется в локальную папку `exports\`, и показывается сообщение.
Основные данные (настройки, шаблоны) всегда остаются на системном диске — JARVIS работает и на HDD, а скорость
диска измеряется бенчмарком.

Запись файлов атомарная (через временный файл), операции с диском выполняются вне потока интерфейса.
