# Бенчмарк JARVIS

## Когда запускается

**Только по явному запросу пользователя:**

* кнопка «Провести бенчмарк» на странице «Производительность»;
* голосовая команда: «Джарвис, проведи бенчмарк» (синонимы: «запусти бенчмарк», «проверь производительность»,
  «тест производительности»).

Перед запуском всегда показывается предупреждение:

> JARVIS выполнит проверку производительности. На время тестирования нагрузка на компьютер может увеличиться.

с кнопками «Начать» и «Отмена» (голосом — «да» / «начать» или «нет» / «отмена»). Бенчмарк **никогда** не запускается
при старте, по таймеру, после обновления, при смене или импорте профиля. В коде нет автоматического варианта запуска:
`BenchmarkTrigger` содержит только `Button` и `VoiceCommand`, а тест `Benchmark_NeverStartsAutomatically` это проверяет.
Для CI есть явный ключ командной строки `JARVIS.exe --selftest --benchmark`.

## Один комплексный сеанс

`BenchmarkService` выполняет все проверки за один сеанс, повторный параллельный запуск отклоняется.
Этапы на экране — реальные (по мере завершения проверок): «Сбор системных сведений» → «Проверка производительности»
→ «Анализ результатов» → «Подбор профиля». Можно нажать «Отменить бенчмарк» или сказать «стоп»: проверка
прерывается, отчёт не сохраняется, настройки не меняются.

| Проверка | Что измеряется | Безопасность |
|---|---|---|
| Система (Windows) | процессор, ядра, ОЗУ всего/свободно, загрузка CPU, ОС, экран, тип диска (seek penalty) | только чтение |
| Нагрузка JARVIS | CPU в простое за 2 с, память, потоки, куча .NET | только чтение |
| Голос | наличие модели, время инициализации, память, слов в грамматике, RTF на подготовленном сигнале; точность — только по записям пользователя | микрофон открывается только при отмеченном флажке, звук не записывается |
| OCR | время инициализации, время на тестовом изображении при 1×/1,5×/2×, точность по известному тексту | своё тестовое изображение |
| UI Automation | список окон, обход дерева, поиск кнопки, повторная проверка после изменения, нажатие через InvokePattern, чтение элемента | собственное тестовое окно JARVIS; мышь и клавиатура не используются |
| Шаблоны | накладные расходы шага, условия, точность ожидания, обработка ошибки, реакция на остановку, параллельные сценарии, память | песочница без реальных действий |
| Диск | запись/чтение 8 МБ, мелкие записи, доступность дополнительного места | временные файлы, удаляются |

Если проверка не удалась или не применима, показатель отмечается «Недоступно» с причиной; остальные проверки
продолжаются. Тайм-аут одной проверки — 60 с.

## Точность распознавания речи

Синтезированная речь для русской модели cmusphinx не подходит, поэтому точность считается **только** по вашим
записям: положите в папку `%LOCALAPPDATA%\JARVIS\benchmark-audio` пары `команда1.wav` (16 кГц, 16 бит, моно) +
`команда1.txt` (ожидаемый текст). Без записей показатель «Недоступно».

## Анализ и рекомендации

`RecommendationService` — правила без нейросетей. Для каждого изменения показываются: параметр, текущее значение,
рекомендуемое, почему, что изменится, на каком измерении основано, уверенность (низкая/средняя/высокая).
Пороги: RTF > 0,5 — медленно (> 0,3 — умеренно); OCR при 2× > 2500 мс (> 1200); обход UIA > 1000 мс (> 400);
≤ 2 потоков CPU, < 4,5 ГБ ОЗУ, < 1 ГБ свободной памяти — сильные признаки слабого ПК. Тип диска сам по себе
не определяет профиль. Если всё в порядке — изменения не придумываются, отчёт говорит, что текущие настройки подходят.

Затем рекомендации сравниваются со всеми профилями (базовыми, пресетами и пользовательскими): точное совпадение,
близкое, частичное или нет подходящего. Подходящий пользовательский профиль предлагается наравне со встроенными.

## Действия после бенчмарка

«Использовать рекомендуемый профиль», «Выбрать другой профиль», «Применить рекомендуемые настройки»,
«Сохранить рекомендации как новый профиль», «Создать копию существующего профиля», «Оставить текущие настройки»,
«Экспортировать отчёт», «Закрыть». **Ничего не применяется автоматически**; перед применением показывается список изменений
и требуется подтверждение. Существующие профили не перезаписываются — рекомендации сохраняются как новый профиль.

## Отчёты

Каждый завершённый бенчмарк сохраняется в `%LOCALAPPDATA%\JARVIS\reports\benchmark-*.json` (дата, версия, система,
значения, недоступные показатели, рекомендуемый профиль, значения и причины). «Открыть последний отчёт» показывает его
без нового запуска, с предупреждением, что после смены оборудования или обновлений результаты могут устареть.
Экспорт — Markdown или JSON. Результаты никуда не отправляются.
