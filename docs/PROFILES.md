# Профили производительности

## Виды профилей

* **Базовые**: «Средний ПК», «Слабый ПК». Встроены в программу, не удаляются и не изменяются (при «редактировании»
  создаётся копия). Если файлы данных повреждены, базовые профили всё равно доступны.
* **Пресеты**: «Максимальная экономия», «Сбалансированный», «Быстрый отклик», «Работа с несколькими приложениями».
* **Пользовательские**: создаются на странице «Производительность».

## Действия

| Действие | Где |
|---|---|
| Активировать / выбрать | карточка профиля или «Изменить профиль…» — сначала показывается список изменений |
| Создать | «Создать профиль» (на основе активного) или «Сохранить текущие значения как профиль» |
| Редактировать | все параметры с допустимыми диапазонами; неверные значения не сохраняются |
| Копировать, переименовать | карточка профиля (имена уникальны) |
| Сбросить к исходному | для профилей, созданных на основе встроенного |
| Сравнить | «Сравнить профили…» или «Сравнить с текущим» |
| Экспортировать / импортировать | JSON; при импорте — предпросмотр, ошибки и предупреждения до сохранения |
| Удалить | только пользовательские, с подтверждением |

Если активный профиль изменён вручную, рядом с названием показывается «(изменён)». Если параметры распознавателя
изменились, голосовой движок перезапускается, и об успехе сообщается только после перезапуска.

## Формат файла (схема 1)

```json
{
  "SchemaVersion": 1,
  "Data": {
    "Id": "user-…",
    "Name": "Мой ноутбук",
    "Description": "…",
    "Kind": "User",
    "BasedOn": "builtin-low",
    "Parameters": { "hud.animations": 0, "exec.stepDelayMs": 250, "ocr.scale": 1.5, "voice.maxHmmPf": 1500 }
  }
}
```

Файлы: `%LOCALAPPDATA%\JARVIS\profiles\*.json`. Правила проверки:

* схема новее поддерживаемой — ошибка; файл без `SchemaVersion` (формат 0, ключи вида `StepDelayMs`) мигрируется;
* значение вне диапазона или не число — ошибка, профиль не импортируется;
* неизвестный ключ — предупреждение, ключ пропускается;
* ключ безопасности — предупреждение, ключ отбрасывается;
* отсутствующий параметр — берётся из базового профиля (`BasedOn`, иначе «Средний ПК») с предупреждением;
* повреждённый файл при запуске перемещается в папку `corrupt` и не мешает работе.
