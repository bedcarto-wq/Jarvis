# Безопасность

## Принципы

* **Локально.** Ни звук, ни текст, ни скриншоты никуда не отправляются; сетевых обращений нет
  (кроме открытия сайтов по вашей команде и разовой загрузки моделей скриптом).
* **Без повышения прав.** Манифест `asInvoker`; JARVIS не запрашивает права администратора.
  Окна программ, запущенных от администратора, Windows не даёт управлять из обычного процесса (UIPI) — это ожидаемо.
* **Шаблоны — данные, а не код.** Произвольные скрипты в шаблонах выполнить нельзя.
* **Удаление — в корзину**, перемещение файлов отменяемо («отмени действие»).

## Опасные действия

Категории: удаление файлов, форматирование дисков, установка программ, изменение системных настроек,
запуск от администратора, запуск скриптов, выключение/перезагрузка, отправка сообщений,
публикация данных, покупки, пользовательская.

Для каждой категории в разделе «Безопасность» включается обязательное подтверждение (по умолчанию —
для всех). Также можно перечислить опасные сочетания клавиш (по умолчанию `Shift+Delete`, `Win+R`,
`Win+X`, `Ctrl+Shift+Enter`) и пометить любой блок шаблона как опасный (например, `Enter` в мессенджере).

Подтверждение — окно с кнопками и голосовой ответ «да»/«нет». Нет ответа — действие **не выполняется**.

## Остановка

* Стоп-слово (по умолчанию «жёпа») — наивысший приоритет, работает в любом состоянии, в том числе
  когда JARVIS отключён голосом или говорит.
* Кнопка «Стоп» на главной, пункт трея, команда «стоп».
* При остановке, ошибке или аварийном завершении отпускаются все клавиши-модификаторы и кнопки мыши,
  которые JARVIS мог удерживать.

## Приватность данных

Журнал хранится в памяти; файл журнала пишется только в режиме отладки (`%LOCALAPPDATA%\JARVIS\logs`).
Записи звука не сохраняются.
