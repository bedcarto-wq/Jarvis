# JARVIS — локальный голосовой оператор рабочего стола Windows

JARVIS управляет компьютером голосом: открывает и закрывает программы, переключает окна,
открывает сайты, меняет громкость, делает скриншоты, нажимает кнопки в интерфейсе и
выполняет пользовательские **шаблоны** (сценарии из блоков). Всё работает **локально**,
**без нейросетей** и **без облачных сервисов**.

> Статус: ранняя версия (0.1). Код собирается и проходит автоматические тесты, но часть
> возможностей требует ручной проверки на реальном ПК — см. раздел «Что проверено».

## Возможности

| Область | Что умеет |
|---|---|
| Голос | Фраза активации «Джарвис» / «Окей, Джарвис», окно команды, стоп-слово (по умолчанию «жёпа») с наивысшим приоритетом, «отключись»/«включись», звуковые сигналы, голосовые ответы (SAPI) |
| Программы | Каталог: встроенные (Блокнот, Проводник, Калькулятор, Chrome, Edge, Firefox, Telegram, Discord, Steam, VS Code…), автопоиск по меню «Пуск» и App Paths, ручное добавление, синонимы |
| Окна | Переключение, свернуть/развернуть/закрыть, показать рабочий стол |
| Браузер | Открыть сайт по названию («открой сайт ютуб») или адресу, вкладки |
| Система | Громкость (CoreAudio), скриншот, копировать/вставить/выделить всё, отмена последнего действия |
| Шаблоны | Визуальный редактор (дерево блоков, перетаскивание), 24 вида блоков, условия, повторы, вложенные шаблоны, повторные попытки, импорт/экспорт JSON, голосовое создание («создай шаблон» → «добавь …» → «сохрани») |
| Поиск элементов | Якоря («запомни как …») → UI Automation → OCR Tesseract (классический движок) → относительные/абсолютные координаты |
| Безопасность | Подтверждение опасных действий голосом или кнопкой, мгновенная остановка, отпускание всех зажатых клавиш, удаление в корзину, без автоповышения прав |
| Производительность | Профили «Средний ПК» и «Слабый ПК», 4 пресета, свои профили (создать, копировать, переименовать, редактировать, сравнить, импорт/экспорт, удалить), бенчмарк **только по запросу** с рекомендациями и подбором профиля, лёгкий мониторинг, дополнительное место хранения (HDD) |
| Интерфейс | Главное окно (9 разделов), HUD-индикатор состояния поверх окон (не перехватывает клики), иконка в трее, автозапуск |

## Быстрый старт

1. Скачайте `JARVIS-Windows-x64.zip` из артефактов GitHub Actions (вкладка **Actions** → последний успешный запуск `build`) и распакуйте в любую папку.
2. Запустите `scripts\install-models.cmd` — скрипт один раз скачает локальные модели:
   модель распознавания речи Vosk для русского языка (~45 МБ) и языковые данные Tesseract (rus, eng).
   Модель PocketSphinx скачивается только с ключом `-WithPocketSphinx`.
3. Запустите `JARVIS.exe`. На вкладке «Главная» виден чек-лист готовности (микрофон, модель, OCR, голос TTS).
4. Скажите: **«Джарвис, открой блокнот»**.

Установка .NET не нужна — сборка self-contained. Требуется Windows 10/11 x64
(подробности и оговорки — [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)).

## Примеры команд

```
Джарвис, открой блокнот            Джарвис, переключись на хром
Джарвис, закрой телеграм           Джарвис, сверни окно / разверни окно
Джарвис, покажи рабочий стол       Джарвис, открой сайт ютуб
Джарвис, громкость пятьдесят       Джарвис, сделай скриншот
Джарвис, новая вкладка             Джарвис, запусти шаблон рабочий режим
Джарвис, запомни как кнопка отправить   (наведите курсор на элемент)
Джарвис, отключись / включись      «жёпа» — немедленная остановка
Джарвис, открой браузер хром        Джарвис, проведи бенчмарк (спросит подтверждение)
```

Без голоса любую команду можно ввести текстом на вкладке «Главная».

## Что проверено

* Сборка `dotnet build -c Release` и автоматические тесты (`dotnet test`) — Linux и GitHub Actions (Windows).
* Настоящий декодер PocketSphinx с русской моделью: загрузка, грамматика команд, отбрасывание тишины/шума, скорость.
* Самопроверка собранного `JARVIS.exe --selftest --desktop` на Windows-раннере GitHub Actions
  (загрузка нативных библиотек, OCR, SAPI, сквозной сценарий «открой/сверни/закрой блокнот» через текстовый конвейер команд).
* Профили, бенчмарк (оркестрация, отмена, «Недоступно», рекомендации, подбор профиля, отсутствие автозапуска и
  автоприменения), русский набор команд — автотесты; в CI собранный `JARVIS.exe --selftest --benchmark` проводит
  один реальный бенчмарк на Windows-раннере.
* **Не проверено автоматически:** точность распознавания живого голоса, работа с реальным микрофоном,
  HUD/трей глазами, сценарии в конкретных программах. Это нужно проверить вручную.

## Технологии

C# / .NET 10, WPF; Vosk (Kaldi, Apache-2.0) + модель vosk-model-small-ru-0.22 — основное распознавание;
PocketSphinx 5 (CMU Sphinx, GMM-HMM, BSD) + модель cmusphinx-ru-5.2 — запасной движок;
Windows SAPI (System.Speech) — синтез речи и резервное распознавание; NAudio — микрофон и громкость;
UI Automation; Tesseract 5 в режиме классического движка (без LSTM). Лицензии сторонних
компонентов — [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). Лицензия проекта — MIT.
